# UI components

Reusable interface components for the application.
Shared data contracts and stay fixtures live in `types/`; page-specific compositions live in `app/`.

- `site-header.tsx`: top navigation and search controls.
- `search-bar.tsx`: segmented search and filters.
- `stay-card.tsx`: reusable home/catalog listing card.
- `home-view.tsx` and `catalog-view.tsx`: page sections.
- `app-navigation.tsx`: responsive bottom navigation.
